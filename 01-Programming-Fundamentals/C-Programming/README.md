# C Programming – Introduction to Programming

This folder contains my practice codes from the **Introduction to Programming in C** course.

It covers the fundamentals of C programming step by step — from basic syntax to arrays, strings, functions, pointers, recursion, and 2D arrays — along with problem-solving practice.

Many of the problem-solving files are solutions to the popular **Assiut University Training - Newcomers** sheets on Codeforces.

---
