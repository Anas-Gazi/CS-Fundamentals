# Introduction to C++ for DSA

This folder contains my practice codes from the **Introduction to C++ for DSA** course (Phitron).

It focuses on the essential C++ features needed for Data Structures & Algorithms and Competitive Programming:
- C++ basics & STL-friendly syntax
- Dynamic memory allocation
- Object-Oriented Programming (Classes & Objects)
- String handling
- Array of objects
- Sorting and basic problem solving

---

## 📂 Module Overview

| Module | Topic | What you will find |
|--------|------|--------------------|
| **module1** | C++ Basics | Input/Output, if-else, switch, ternary, min/max, swap, setprecision, string, ascii |
| **module2** | Dynamic Memory | Dynamic variables, dynamic arrays, returning dynamic arrays from functions |
| **module2.5** | Practice Day | Extra practice on dynamic memory |
| **module3** | Class & Object | Classes, objects, constructors, `this` pointer, dynamic objects, sorting |

| **module8** | Final / Problem Solving | Sorting, reverse, smallest pair, and other practice problems |
