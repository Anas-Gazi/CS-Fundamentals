

# CS-Fundamentals

A curated collection of programming exercises and algorithm implementations designed to build a strong foundation in Computer Science and Data Structures & Algorithms (DSA). The repository contains solutions and practice problems written in **C** and **C++**, organized by concept, week, and progression level.

## 📁 Repository Structure

- `Introduction to Programming/Cprogramming/` - Core C programming concepts including I/O, control flow, arrays, 2D arrays, pointers, functions, and strings.
- `Introduction to c++ for DSA/` - C++ fundamentals tailored for DSA and competitive programming, covering dynamic memory, classes, objects, and string operations.
- `Basic Data Stracture/` - Essential data structures and algorithmic techniques such as complexity analysis, linear & binary search, sorting, and linked list nodes.
- `Problem-Solving_p1/` & `final/` - Standalone problem-solving exercises and contest-style implementations.
- Root directory - Additional standalone algorithm implementations (e.g., `Y_Range_sum_query.cpp`).

## 🛠️ Prerequisites

- A C/C++ compiler (`gcc` and `g++`)
- Command-line interface access
- Basic familiarity with programming concepts

## 🚀 Installation & Usage

This repository consists of standalone source files and does not require a package manager or build system. You can compile and run them directly from the terminal.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Anas-Gazi/CS-Fundamentals.git
   cd CS-Fundamentals
   ```

2. **Compile and run a C program:**
   ```bash
   gcc "Introduction to Programming/Cprogramming/Module2/arithmetic.c" -o arithmetic
   ./arithmetic
   ```

3. **Compile and run a C++ program:**
   ```bash
   g++ -std=c++17 "Introduction to c++ for DSA/module1/ascii.cpp" -o ascii
   ./ascii
   ```

> 💡 **Note:** Many C++ files include `<bits/stdc++.h>` and are optimized for competitive programming environments. Compile with `-std=c++17` or higher for best compatibility.

## 📚 Topics Covered

- **Core Programming:** Variables, I/O, conditionals, loops, functions, and control structures
- **Arrays & Strings:** 1D/2D arrays, string manipulation, frequency counting, concatenation, and array operations
- **Memory & Pointers:** Dynamic memory allocation, pointers, references, and memory management
- **Data Structures:** Linked list nodes, dynamic arrays, and object-oriented basics (classes & objects)
- **Algorithms:** Linear & binary search, sorting (selection sort, `qsort`), range sum queries, and time complexity (`O(n)`)
- **Problem Solving:** Pattern printing, mathematical operations, frequency arrays, and competitive programming fundamentals
